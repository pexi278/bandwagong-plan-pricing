## 搬瓦工是个什么服务商

搬瓦工（BandwagonHost）是一家美国 VPS 服务商，主营 KVM 架构的 VPS，控制面板是自家的 KiwiVM。它在国内用户里知名度高，核心原因就一个：针对中国大陆方向做了优化线路，尤其是 CN2 GIA 和 CN2 GIA-E 这类电信双向优化方案，这是市面上很多同价位商家给不了的。

支持支付宝、微信、银联等付款方式，对国内用户来说下单门槛不高。所有套餐都是自管理服务（self-managed），给完整 root 权限，官方只管机器和网络，环境配置靠自己——买之前要有这个心理准备。

常规套餐承诺 99.95% 在线率；后来推出的 ECOMMERCE SLA 系列把承诺提到了 99.99%，并附带宕机赔付条款，这个后面单独说。

## 这些套餐的线路到底差在哪

搬瓦工服务器选购的核心从来不是 CPU 和内存，而是线路。三句话讲清楚：

**KVM 常规套餐**走普通国际线路，白天没问题，电信用户晚高峰容易拥堵。它便宜是应该的，这份钱里不包含线路优化。

**CN2 GIA-E** 走电信 CN2 GIA 双向优化，去程回程都走电信自己的精品网络，不绕公网。这是它晚高峰依然稳定的原因，也是它比 KVM 贵的部分。附带的好处是可迁移机房多，联通用户可以把机房切到大阪 JPOS_1（软银线路），联通方向的体验会更好。

**香港/东京/大阪/新加坡 CN2 GIA** 是独立的高端系列，物理距离近，延迟直接从美西的 150ms 上下降到亚太机房的几十毫秒级别。代价上面已经写了：流量少一半以上，价格翻倍起步。

一句话总结：线路钱花在哪，取决于你的用户在哪。给国内用户看的服务，省什么都别省线路；纯海外业务，KVM 反而是理性选择。

## 买完之后你能做什么

几个对使用影响很大的后台能力，都包含在套餐里：

- **机房自由迁移**：KVM 和 CN2 GIA-E 系列支持在包含的机房之间免费自动迁移，迁移后 IP 会更换。感觉当前机房晚高峰不行，随时切一个试试。
- **免费自动备份和快照**：两项都不额外收费，动手折腾系统之前先拍个快照，玩坏了能秒回。
- **系统一键重装**：CentOS、Debian、Ubuntu、Rocky Linux、AlmaLinux 都能一键换，也支持手动挂 ISO。
- **套餐升级**：后台可以对符合条件的 VPS 补差价升级配置，前期不用一步到位买大的。
- **IPv6 支持**：每个套餐带一个独立 IPv4 和一个 /64 的 IPv6 子网。

## 缺点和限制，买前想清楚

优点说完了，这几条限制同样真实：

- **价格不便宜**。同配置下，优化线路的搬瓦工比很多"性价比 VPS"贵。你付的钱里相当一部分是线路成本，这是它的定位，不是溢价水分。
- **没有 DDoS 防护**。为了保证优化线路质量，所有套餐都不提供流量清洗，IP 遭到大流量攻击可能被临时空路由（nullroute）。业务容易被攻击的话，需要自己前置高防或 CDN。
- **流量配额偏紧**。尤其是香港、东京系列，$89.99/月只有 0.5TB 流量，跑大流量业务前先算清楚。
- **完全自管理**。没有托管服务，出问题靠自己排查或发工单，新手要有基本 Linux 功底。
- **热门套餐会缺货**。低价限量版常年处于售罄状态，常规款偶尔也会短暂缺货，看中了别犹豫太久。

## 购买流程简述

流程很短：选套餐和计费周期 → 加购物车 → 结算页填注册信息、选支付宝等付款方式 → 付款后几分钟内开通，KiwiVM 后台就能看到机器。开通后第一件事建议装好系统、拍个快照，再跑一遍去程回程路由，确认分到的机房符合预期，不满意直接在后台迁移换机房。

## 常见问题

**搬瓦工服务器适合新手吗？**
系统安装和开通是傻瓜式的，但后续使用完全是自管理。如果连 SSH 是什么都不清楚，先补一下 Linux 基础再买，或者直接选带面板的一键环境。

**CN2 GIA-E 年付 $169.99 和 KVM 年付 $49.99，差在哪？**
差在线路。前者是电信 CN2 GIA 双向优化加十几个可切换机房，后者是普通国际线路。主要给国内用户访问，这 $120 是花得值的；纯海外业务则相反，KVM 更划算。

**香港套餐 $89.99/月，为什么流量只有 0.5TB？**
香港机房的带宽成本远高于美国，这是全行业的普遍情况，不是搬瓦工单独抠门。流量需求大就选美国 CN2 GIA-E，延迟和流量二选一。

**付款能用支付宝吗？**
可以，结算页支持支付宝、微信、银联等方式，账单按美元计价，支付时按汇率折算。

**买错了能换套餐吗？**
配置不足可以在后台补差价升级。机房则在套餐允许的范围内免费切换。下单前确认好计费周期，年付改月付这类操作就没那么自由了。
